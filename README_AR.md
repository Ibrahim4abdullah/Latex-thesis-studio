# LaTeX Thesis Studio v1.0

نسخة مطورة من محرر LaTeX مكتبي للأطروحات، بواجهة قريبة من Overleaf، ومصممة لتعمل كحزمة Windows مستقلة.

## أهم الوظائف

- محرر متعدد الملفات مع أرقام أسطر وتلوين Syntax.
- إكمال تلقائي لأوامر LaTeX وإغلاق تلقائي للأقواس.
- شجرة ملفات المشروع وإنشاء ملفات فصول جديدة.
- بحث داخل المشروع بالكامل.
- حفظ تلقائي، وبناء تلقائي اختياري.
- استيراد مشروع Overleaf بصيغة ZIP وتصدير المشروع ZIP.
- معاينة PDF داخل التطبيق.
- XeLaTeX وLuaLaTeX وlatexmk.
- BibLaTeX وBiber.
- قالب أطروحة عربي/إنجليزي.
- سجل بناء، والانتقال إلى سطر الخطأ بالنقر المزدوج عندما يكون الخطأ بصيغة file.tex:line.
- اكتشاف ملفات .sty الناقصة.
- البحث عن الحزمة المالكة للملف الناقص باستخدام tlmgr.
- تثبيت الحزم الناقصة من CTAN بعد موافقة المستخدم، ثم إعادة البناء.

## النسخة Self-contained

شغّل `build/BUILD_WINDOWS.bat` على جهاز Windows مخصص للبناء. سكربت البناء يقوم بتجهيز النسخة النهائية التي تحتوي داخلها على:

- البرنامج نفسه كملف EXE ومكتباته.
- Python runtime المضمّن بواسطة PyInstaller.
- PySide6.
- TinyTeX/TeX Live محمول داخل مجلد البرنامج.
- XeLaTeX وLuaLaTeX وlatexmk وBiber.
- مجموعة موسعة من حزم الأطروحات والرياضيات والجداول والمراجع والعربية.

بعد إنشاء الـ Release، جهاز المستخدم النهائي لا يحتاج إلى تثبيت Python أو MiKTeX أو TeX Live.

## ملاحظة مهمة عن الحجم

الهدف هو حزمة متوسطة الحجم. لذلك لا يتم تضمين scheme-full بالكامل. عند استخدام حزمة نادرة غير موجودة، يستطيع البرنامج تثبيتها بنفسه داخل TinyTeX المدمج من CTAN بعد موافقة المستخدم.
